## `src/pdac_cfrna/training.py`

Gene selection and model training for one resolved run configuration.

- Uses: `bundle`, `config`, `data`, `experiment`, `models`, `run_config`, `runs`, `selection`
- Used by: `scripts/check_task_splits.py`, `scripts/replicate_de_selection.py`, `scripts/run_paper_replication.py`, `scripts/select_threshold.py`, `scripts/train_model.py`

**Functions**

- `load_for_task(dataset_cfg: DatasetConfig, task_name: str) -> Dataset`
  Load a dataset with one task's labels (and sample selection) applied.
- `select_experiment_table(cfg: RunConfig) -> pd.DataFrame`
  The gene-selection table (variance filter, Wilcoxon, BH) on the training rows only.
- `select_experiment_genes(cfg: RunConfig) -> list[str]`
  The genes of a run: the significant genes of the gene-selection table.
- `train_bundle(ds: Dataset, cfg: RunConfig, genes: list[str], extra_metadata: dict[str, Any] | None=None) -> ModelBundle`
  Fit the paper's pipeline on the training rows of `ds` and package it with its normalizer.
